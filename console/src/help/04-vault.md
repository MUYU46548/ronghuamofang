# 知识库（Obsidian）怎么接

## 一、它是什么

写作时的“正典检索”会读你 Obsidian 库里的笔记，作为设定参考。库本体**只读**，程序不会写你的库。

## 二、要配的两件事

1. **库路径**：`config/system.yaml` 的 `obsidian.vault_path`（或本地覆盖 `config/system.local.yaml`）
2. **目录映射**：你库里的角色 / 地点 / 势力 / 概念 / 年表分别在哪个目录

默认**不预设**任何目录映射（每个库的结构都不一样，写死一套只会对某一个人成立）。
在**设置 → 知识库 → 设定目录**里逐类点选；也可以写在本地覆盖里：

```yaml
obsidian:
  vault_dirs:
    characters: "我的设定/人物"
    locations: "我的设定/地点"
```

## 三、排除不想进的目录

设置 → 风格与提示词 → 知识库扫描。界面会列出库里扫到的目录，**勾掉的目录不进检索**（参考作品、草稿区、模板归档都该排除）。

- 保存后**立即生效**，下次导入设定集就按新的扫描面走；
- 界面上“共 N 篇，其中 M 篇进入检索”的数字就是实际扫描面，不是估算；
- 默认恒排除：`.obsidian` `.git` `.hermes` `.agent_context`，以及你自己的沙盒目录。
  这些是**追加**语义——你写一项不会把默认四项顶掉。

## 四、常见疑问

**改了排除项要不要重启？**
不要。0.7.22 起排除项是调用时读取的，保存即生效（此前这里有过"界面显示排除、导入时照样收"的缺陷）。

**目录名不匹配会怎样？**
扫描会打告警并跳过该目录，不会静默扫零。看到告警就去改 `vault_dirs`。

**能不能同时挂多个库？**
能。**多库同时读**是现在的默认行为：当前库永远参与，其余库按“启用”开关一起读。

在“我的库”里：
- **启用 / 停用**：只决定这个库这轮参不参与扫描，**笔记文件一个都不动**；当前库不能停用
  （它是“当前在用的库”，停掉写作时就没有知识库输入了）；
- **切到这个库**：换当前库（当前库在同名冲突里优先级最高）；
- **移出列表**：只从列表里去掉，笔记一个都不会少；想再连回来，重新填一次路径；
- **检查同名冲突**：扫一遍所有启用的库，列出“两个库里都有这个名字”的条目，
  说明这次用了哪个库的、忽略了哪个库的。**当前库优先**是唯一规则，不做“看情况合并”；
- 每个库会**记住自己的排除项**（A 库的“参考作品”和 B 库的“草稿”互不影响）。

为什么同名条目不让系统自己合并：两个库都有“沈砚”时，合并规则猜错一次就会覆盖掉你手写的
角色卡——那是在改你的设定，不是功能。所以系统只做两件事：按“当前库优先”取一条，
并把被覆盖的那条**点名给你看**。要哪条说了算，你把那个库切成当前库就行。

如果哪天只想要单库，点“改成单库模式”即可（书签一个都不会删）。
