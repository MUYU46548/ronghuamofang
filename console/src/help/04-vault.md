# 知识库（Obsidian）怎么接

## 一、它是什么

写作时的“正典检索”会读你 Obsidian 库里的笔记，作为设定参考。库本体**只读**，程序不会写你的库。

## 二、要配的两件事

1. **库路径**：`config/system.yaml` 的 `obsidian.vault_path`（或本地覆盖 `config/system.local.yaml`）
2. **目录映射**：你库里的角色 / 地点 / 势力 / 概念 / 年表分别在哪个目录

默认映射是“设定/人物”“设定/地点”“设定/势力”“设定/概念”“年表”。你的库不叫这些，就得在本地覆盖里写成你自己的：

```yaml
obsidian:
  vault_dirs:
    characters: "我的设定/人物"
    locations: "我的设定/地点"
```

## 三、排除不想进的目录

设置 → 风格与提示词 → 知识库扫描。界面会列出库里扫到的目录，**勾掉的目录不进检索**（参考作品、草稿区、模板归档都该排除）。

- 保存后**立即生效**，下次导入设定集就按新的扫描面走；
- 界面上“共 N 篇，其中 M 篇进入检索”的数字就是实际扫描面，不是估算；
- 默认恒排除：`.obsidian` `.git` `.hermes` `.agent_context`，以及你自己的沙盒目录。
  这些是**追加**语义——你写一项不会把默认四项顶掉。

## 四、常见疑问

**改了排除项要不要重启？**
不要。0.7.22 起排除项是调用时读取的，保存即生效（此前这里有过"界面显示排除、导入时照样收"的缺陷）。

**目录名不匹配会怎样？**
扫描会打告警并跳过该目录，不会静默扫零。看到告警就去改 `vault_dirs`。

**能不能同时挂多个库？**
可以存多个库，但**同一时刻只有一个生效**（和 Obsidian 一样：库是独立的，切换就是换当前库）。

在“我的库”里：
- **切到这个库**：换当前库。切换**不动任何笔记文件**，只是换"现在读哪个"；
- **移出列表**：只从列表里去掉，笔记一个都不会少；想再连回来，重新填一次路径；
- 每个库会**记住自己的排除项**，切回来不用重新勾（正因如此：A 库的"参考作品"目录在 B 库里可能根本不存在，共用一份排除项等于两边都错）。

为什么不"同时读多个库"：导入设定集是**整体替换**。两个库都有"沈砚"时，
合并规则猜错一次，就会覆盖掉你手写的角色卡——那是在改你的设定，不是功能。
所以宁可让你按需要切，也不替你决定"这两个沈砚是不是同一个人"。
