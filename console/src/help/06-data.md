# 我的东西都存在哪里

## 一、三个位置

| 位置 | 放什么 | 升级会不会动 |
|---|---|---|
| 安装目录 `resources/payload` | 程序代码、出厂提示词、出厂模板 | 会（整包替换） |
| 工作区 `%APPDATA%\绒花墨坊\workspace` | **你的书、设定、大纲、正文、日志** | 不会 |
| 项目 `config/` | 书名、路径、模型选择、你要调整的口径 | 只补缺失键，不覆盖你填过的值 |

工作区里的 `data/` 是**你的产物**，任何情况下都不被覆盖。升级只刷 `scripts/`（代码），
`prompts/` 按"你改没改过"逐文件判断（见“提示词改坏了怎么退回去”）。

## 二、想彻底重来

“项目”页有“一键还原出厂测试项目”：滑条拖到底才解锁，会把进度清掉、素材铺回出厂样例。
那是给试跑用的，别对正在写的书用。

真要备份，直接复制整个 `%APPDATA%\绒花墨坊\workspace` 目录即可——里面没有别的机关的。

## 三、外部 Agent 能改我的文件吗

能读、能调流水线，但有几条是禁的：

- 事件勾选（`/judge/events`）与逐句裁定（`/judge/sentence`）：这是作者的判断，Agent 只读不可签；
- `/chapters/save`：正文写入是 GUI-only（双因子 + 禁用名单）；
- 破坏性操作（打回 / 归档覆盖）前会强制快照。

## 四、密钥

API Key 存在项目 `.env`（不进 git）。界面上只显示前 4 后 4，任何时候都不回显明文。
配置只需点“填入 Key”，不用手改文件。
