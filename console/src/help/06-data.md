# 我的东西都存在哪里

## 一、三个位置

| 位置 | 放什么 | 升级会不会动 |
|---|---|---|
| 安装目录 `resources/payload` | 程序代码、出厂提示词、出厂模板 | 会（整包替换） |
| 工作区 `%APPDATA%\绒花墨坊\workspace` | **你的书、设定、大纲、正文、日志** | 不会 |
| 项目 `config/` | 书名、路径、模型选择、你要调整的口径 | 只补缺失键，不覆盖你填过的值 |

工作区里的 `data/` 是**你的产物**，任何情况下都不被覆盖。升级只刷 `scripts/`（代码），
`prompts/` 按"你改没改过"逐文件判断（见“提示词改坏了怎么退回去”）。

## 二、想彻底重来

“项目”页有“一键还原出厂测试项目”：滑条拖到底才解锁，会把进度清掉、素材铺回出厂样例。
那是给试跑用的，别对正在写的书用。

真要备份，直接复制整个 `%APPDATA%\绒花墨坊\workspace` 目录即可——里面没有别的机关的。

## 三、外部 Agent 能改我的文件吗

能读、能调流水线，但有几条是禁的：

- 事件勾选（`/judge/events`）与逐句裁定（`/judge/sentence`）：这是作者的判断，Agent 只读不可签；
- `/chapters/save`：正文写入是 GUI-only（双因子 + 禁用名单）；
- 破坏性操作（打回 / 归档覆盖）前会强制快照。

## 四、密钥

API Key 存在项目 `.env`（不进 git）。界面上只显示前 4 后 4，任何时候都不回显明文。
配置只需点“填入 Key”，不用手改文件。

## 五、产物速览：显示的就是盘上有的

流水线页签的“产物速览”那五行的判据只有一个：**工作区里真有这个文件**。

- 文件还没产出来 → 写“尚未产出”，并且**不给**预览/打开按钮（不会出现点了报错的情况）；
- Word 成品只认**当前这本书**的成品。换书之后 `output/` 里上一本书的 docx 会被
  一起归档进书档（`data/books/<书名>/output/`），不会再冒充这一本的成品；
- “素材体检”只在阶段 1 跑过之后才有。没有它不等于出错，就是还没跑。

## Word 模板：出厂那份是“中性预设”，你自己的模板放你自己电脑上

- 出厂自带一份 **中性预设模板**（`templates/出厂预设模板.docx`）：A4、四边 2.5cm、宋体正文 + 黑体标题、
  书名/作者/目录三个占位符齐全。它**不包含任何人自己的版式偏好**，随包发、升级会整包替换；
- **你自己的模板**（例如你在 Word 里存的那份《小说格式模板》）放在你自己电脑上就行
  （默认位置 `文档\自定义 Office 模板`），然后在“设置 → Word 模板”里把它选进来。
  选的是**路径**，工作区不需要再存一份；
- 你自己的模板**不会**被打包、也不会发给别人 —— 出厂只带上面那份中性预设。

导出时如果模板路径不对（文件被移走/删了），导出会**停下并说清是哪个文件**，不会静默换成别的版式。
