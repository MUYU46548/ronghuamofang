# 引擎、模型与花多少钱

> **2026-11-25 起只有两种运行方式**：DSH 后台执行（默认）与自任务（只出任务书）。
> 直连模型与“Agent 子会话”这两条老通道的代码已经删除，设置页里也不会再看到它们。
> 模型与渠道全部由 DSH 决定 —— 墨坊不保存 key，也不填模型名。

## 一、两种方式，代价完全不同

| | DSH 后台执行（**默认**） | 自任务（只出任务书） |
|---|---|---|
| 谁在调模型 | DeepSeek Harness（在后台跑，不用开界面） | **没人调** —— 程序只写任务书 |
| 花什么 | 你的订阅额度 | **不花钱**（零 token） |
| 用什么模型 | 由 DSH 自己的配置定 | 不涉及 |
| 止烧阈值 | 只有 token 上限有效（金额记账恒 0） | 不涉及（不调用模型） |
| 产出 | 成品 | 任务书（等你或外部助手去执行） |

切引擎：设置 → 引擎与模型 → 点卡片。对下一次运行生效。

> **界面只有两张卡**：DSH 与自任务。没有“回退通道”了 —— DSH 起不来时，
> 唯一能退的是自任务（零 token 出任务书，人工执行）。这是刻意的选择，不是遗漏。

## 从零到成书：你只需要点几次

1. 启动时填书名、章数（引擎默认 DSH，不用改）。
2. 把素材放进 `materials/raw/`。
3. 流水线页找 **“能不能跑？试一章就知道”**：先看五项体检（许可 / 引擎 / DSH 程序 /
   书名素材 / 前置阶段）。全绿后点 **“试写一章（1 次调用）”**。
   跑完这里直接给结论 —— 成了没有、多少汉字、耗多久、DSH 调了几次。
   **不用你去看 progress.json 或 runs.db**，那张卡就是结论。
4. 之后点顶栏 **“▶ 下一步”** 或 **“全自动”**。遇到审批门，点 **“确认放行并继续”**：
   它会自己接着往下跑，不需要你回流水线再点一次运行。
   只想签字、暂时不跑，用旁边那个小的 **“只确认”**。
5. 七阶段走完后点 **“生成 Word 成品”**。

审批门在哪几道、要不要停，全在 **设置 → 审批门** 里勾。
同一页还有一个 **“素材库自主”** 开关：不勾（默认）= 素材归并完会停一次让你看冲突清单；
勾上 = 归并完直接往下跑。


### DSH 后台执行怎么用

电脑上要先装 **DeepSeek Harness**（DSH）。程序就会把每一步交给它的命令行版本去跑，
你不用开着它的界面。

这张卡只换“谁在跑”。**读稿、改段落、采纳候选仍然在绒花墨坊界面里做** ——
DSH 里不会重做一套墨坊界面（配对的 DSH 插件只是把墨坊的工具转给 DSH 里的助手用）。

几个要知道的地方：

- **用的是你 DSH 里那三家渠道**：provider 配置（commandcode / 基元律动 / opencode-go）
  已从桌面端搬到 `headless` 档（`~/.dsh/profiles/headless/cordis.patch.yml`），
  key 在 `~/.dsh/.env`。墨坊不传模型名，只管把任务书递过去。哪天你在 DSH 里换了 key，
  这里一跑就会报凭据错（不会假装跑完）。
- **必须用 headless 档**（2026-11-24 实测）：`desktop` 档被 DSH 明确拒绝命令行调用
  （`profile "desktop" is managed exclusively by the Electron application`），
  填它等于跑不起来 —— 这正是 11 月以前“一章都跑不出”的真原因。
- **不要打开 authorization / deepseek-account 两个插件**：它们会把调用接到官方账户
  并按量计费（2026-11-20 实测 27 次 ¥0.13）。
- **花钱记账是 0，但 token 照记**。所以“花超自动停”只看 token 上限（设置 → 预算与止烧）。
- 点左侧的“🩹 补救”，弹出的自检里会写“DSH 可用 / 不可用”。写“不可用”时，说明机器上没找到
  DSH 的命令行入口，先装 DSH，或把入口路径填进配置文件。

### 自任务模式怎么用

点一次“运行”，程序把这一阶段“该写什么、写到哪、什么样算合格”写成任务书，
放在项目的 `data/state/tasks/self/阶段N/` 里，然后停下（不是失败，也不是等你审批）。

接下来：

1. 打开任务书，按里面写的路径把产物写好（例如大纲写进 `data/outline/global.md`）；
2. 再点一次“运行”。程序只看**文件在不在、合不合格**：齐了就直接放行到下一阶段，
   不齐就重新给你一份任务书。

两个要紧的地方：

- **只认文件，不认“我写完了”这句话**。写了但没写到指定路径 = 没写。
- 正文写作是**一章一交回**：写完这一章再点运行，程序会带着上一章的结尾和摘要，
  给你下一章的任务书（这样上下文才接得上）。

**按钮怎么走**（0.9.1 起）：凡是“让模型动手改字”的按钮，在 self 下分两类。

1. **出任务书**（已经接上的）：**大纲精修**、**整章重写**、**提精修**、**段落重写**（改一段）。
   - 大纲精修：任务书里带当前大纲全文 + 你的意见 + 写回路径；旧版自动备份到 `data/outline/history/`，
     外部改 `data/outline/global.md`，回来点“运行”（阶段 2）复核。
   - 段落重写：任务书里带这一段原文 + 上下两段（只用来接得上），外部只写**这一段的改后文本**到
     `data/self_drafts/para_NN_pX.md`；回来点“看候选”能看到改前/改后，点“采用”才写进正文。
   - 整章重写 / 提精修：任务书里带这一章的现有正文与本章大纲（精修还带你勾的建议），
     外部写到 `data/self_drafts/chapter_NN.md`；
     写完后章节列表那一行会出现“草稿 N 字”，**判据**（有标题 / 汉字数在区间内 / 无占位符 / 不是原样复制）
     过了才能点 **采用草稿** —— 采用时旧稿先备份到 `data/chapters/rewrite_backup/`；
     点 **放弃** 就丢掉草稿，正式稿一个字节不动。

2. **暂时只禁用并说明原因**：重跑本章、运行审查、批量精修、自动重写、
   语义审稿、开局方案 / 写作方向候选。这些要么缺确定性判据（段改写没法自动验），
   要么依赖前置报告（批量精修要审查报告）—— 硬做成任务书等于放任外部乱写，所以先不做。
界面顶部会常驻一条“自任务模式：只出任务书，不调模型”的说明；按钮变灰不是缺陷。
要用它们，把引擎切回 DSH。

零花费、self 下照样能用的：判定回测、结构化检查、去 AI 腔扫描、字数统计、
出书导出、素材导入 —— 这些都是确定性程序，不碰模型。

## 二、六个角色分别是谁

> **DSH 下这张表不参与运行** —— 用哪个模型由 DSH 的配置决定。
> 保留它是为了让你看懂任务书里“这一段是给谁写的”，以及将来接外部执行方时的分工。

| 角色 | 干什么 |
|---|---|
| default | 兜底（没单独指定的调用） |
| architect | 设定 / 世界观 |
| outliner | 大纲 |
| writer | 正文写作（最贵，字数最多） |
| checker | 逻辑检查 |
| reviewer | 审稿 |
| polisher | 润色 |

可以给 writer 用贵的、给 checker 用便宜的——这是省钱的主要手段。

## 三、换供应商要小心

> 这一节只在“你给了外部执行方（或 DSH）自己的模型配置”时有意义。DSH 下墨坊不传模型名，
> 换渠道请在 DSH 那边改。

**模型名跨供应商不通用。** 换了 provider 却留着旧模型名，运行时会直接 404，而且这个项目对 404 是**报错不回落**——那个角色就哑了。

界面会在切换后提示"模型 X 不在新供应商的清单内"，看到这句就顺手把模型也改掉。

## 四、怎么防止烧穿

“设置 → 预算与止烧”有四个值：单请求输出上限、单轮累计上限、预警比例、是否启用。

超出阈值会熔断，不是提醒你继续。**token 上限是 DSH 模式下唯一有效的止烧手段**（金额阈值在那个模式下不生效）。

单请求输出上限的出厂值是 **20 万 token**（2026-11-26 从 5 万调上来）：一次归并 40 多篇素材，
单行 cost_log 的输出就能到 10 万，5 万会让“活干完了才报阶段失败”。
输入框上下箭头按 1000 / 10 万步进，不用点一万次。

### 外部 Agent 跑阶段，要先在你这里签额度（0.9.9 起）

会真调模型的端点（跑阶段、整章重写、审稿、讨论里让 AI 说一轮……）**默认不许外部 Agent 跑**。
要用的时候：设置 → 外部协作 → “外部调用花销授权”，签一个“最多几次 / 几小时内有效”。

- 用完或到期**自动失效**，不需要你记着回来关；
- 被拒时它会收到一句“去桌面端授权”，不是静默失败；
- 授权只有界面能签 —— 外部 Agent 不能给自己签；
- 引擎是 `self` 时这条闸不生效（那个模式只写任务书，不调模型，物理上不花钱）。

### 字数是怎么算的（2026-11-05 起）

**只计汉字**：标点、空格、数字、英文字母都不算。所以“单章 4000 汉字”比以前的
“4000 字（含标点）”要实 —— 旧口径的 5000（含标点）按同等篇幅折算成 4000 汉字。
既有工作区会自动折算一次（只改恰好等于旧出厂值的配置，你自己调过的值不动）。

## 五、这本书花了多少钱

每跑完一轮，程序会自动记一条**本书成本**（章数、汉字数、各阶段时间、墨坊自己调模型
的 token 与费用）。落在 `data/state/book_costs.json`。

**但外部 Agent 花的钱，程序读不到** —— 那笔账记在它自己那边。所以跑完之后请让执行方补一行：

```
python scripts/book_cost.py record --yuan 45 --note "Hermes，12 章"
```

没补就显示“未上报”，程序**不会**按字数瞎折一个数出来。看当前记录：

```
python scripts/book_cost.py
```

> **接外部的东西现在只剩两种**：① **DSH 专用协作**（推荐，也是出厂默认那条）；② 其他 agent 平台走**早期 MCP 通道** —— 能用，但**不保证后续维护**。墨坊内部不再保留内置模型调用。
