# 引擎、模型与花多少钱

## 一、三种引擎，代价完全不同

| | 直连模型 | Agent 子会话 | 自任务（只出任务书） |
|---|---|---|---|
| 谁在调模型 | 程序自己 | 外部 Agent（编程工具里的助手） | **没人调** —— 程序只写任务书 |
| 花什么 | 按 token 计费，真金白银 | 你的订阅额度 | **不花钱**（零 token） |
| 设置里的角色模型表 | **生效** | **不生效**（模型由外部 Agent 定） | 不生效 |
| 止烧阈值 | 金额 + token 都有效 | 只有 token 上限有效（金额记账恒 0） | 不涉及（不调用模型） |
| 产出 | 成品 | 成品 | 任务书（等你或外部助手去执行） |

切引擎：设置 → 引擎与模型 → 点卡片。对下一次运行生效。

### 自任务模式怎么用

点一次“运行”，程序把这一阶段“该写什么、写到哪、什么样算合格”写成任务书，
放在项目的 `data/state/tasks/self/阶段N/` 里，然后停下（不是失败，也不是等你审批）。

接下来：

1. 打开任务书，按里面写的路径把产物写好（例如大纲写进 `data/outline/global.md`）；
2. 再点一次“运行”。程序只看**文件在不在、合不合格**：齐了就直接放行到下一阶段，
   不齐就重新给你一份任务书。

两个要紧的地方：

- **只认文件，不认“我写完了”这句话**。写了但没写到指定路径 = 没写。
- 正文写作是**一章一交回**：写完这一章再点运行，程序会带着上一章的结尾和摘要，
  给你下一章的任务书（这样上下文才接得上）。

**按钮怎么走**（0.9.1 起）：凡是“让模型动手改字”的按钮，在 self 下分两类。

1. **出任务书**（已经接上的）：**大纲精修**、**整章重写**、**提精修**（校对页按建议精修）。
   - 大纲精修：任务书里带当前大纲全文 + 你的意见 + 写回路径；旧版自动备份到 `data/outline/history/`，
     外部改 `data/outline/global.md`，回来点“运行”（阶段 2）复核。
   - 整章重写 / 提精修：任务书里带这一章的现有正文与本章大纲（精修还带你勾的建议），
     外部写到 `data/self_drafts/chapter_NN.md`；
     写完后章节列表那一行会出现“草稿 N 字”，**判据**（有标题 / 汉字数在区间内 / 无占位符 / 不是原样复制）
     过了才能点 **采用草稿** —— 采用时旧稿先备份到 `data/chapters/rewrite_backup/`；
     点 **放弃** 就丢掉草稿，正式稿一个字节不动。

2. **暂时只禁用并说明原因**：段落重写、重跑本章、运行审查、批量精修、自动重写、
   语义审稿、开局方案 / 写作方向候选。这些要么缺确定性判据（段改写没法自动验），
   要么依赖前置报告（批量精修要审查报告）—— 硬做成任务书等于放任外部乱写，所以先不做。
界面顶部会常驻一条“自任务模式：只出任务书，不调模型”的说明；按钮变灰不是缺陷。
要用它们，就把引擎切到直连或子会话。

零花费、self 下照样能用的：判定回测、结构化检查、去 AI 腔扫描、字数统计、
出书导出、素材导入 —— 这些都是确定性程序，不碰模型。

## 二、六个角色分别是谁

| 角色 | 干什么 |
|---|---|
| default | 兜底（没单独指定的调用） |
| architect | 设定 / 世界观 |
| outliner | 大纲 |
| writer | 正文写作（最贵，字数最多） |
| checker | 逻辑检查 |
| reviewer | 审稿 |
| polisher | 润色 |

可以给 writer 用贵的、给 checker 用便宜的——这是省钱的主要手段。

## 三、换供应商要小心

**模型名跨供应商不通用。** 换了 provider 却留着旧模型名，运行时会直接 404，而且这个项目对 404 是**报错不回落**——那个角色就哑了。

界面会在切换后提示"模型 X 不在新供应商的清单内"，看到这句就顺手把模型也改掉。

## 四、怎么防止烧穿

“设置 → 预算与止烧”有四个值：单请求输出上限、单轮累计上限、预警比例、是否启用。

超出阈值会熔断，不是提醒你继续。**token 上限是 hermes 模式下唯一有效的止烧手段**（金额阈值在那个模式下不生效）。

### 字数是怎么算的（2026-11-05 起）

**只计汉字**：标点、空格、数字、英文字母都不算。所以“单章 4000 汉字”比以前的
“4000 字（含标点）”要实 —— 旧口径的 5000（含标点）按同等篇幅折算成 4000 汉字。
既有工作区会自动折算一次（只改恰好等于旧出厂值的配置，你自己调过的值不动）。

## 五、这本书花了多少钱

每跑完一轮，程序会自动记一条**本书成本**（章数、汉字数、各阶段时间、墨坊自己调模型
的 token 与费用）。落在 `data/state/book_costs.json`。

**但外部 Agent 花的钱，程序读不到** —— 那笔账记在它自己那边。所以跑完之后请让执行方补一行：

```
python scripts/book_cost.py record --yuan 45 --note "Hermes，12 章"
```

没补就显示“未上报”，程序**不会**按字数瞎折一个数出来。看当前记录：

```
python scripts/book_cost.py
```
