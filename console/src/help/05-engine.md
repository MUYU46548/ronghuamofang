# 引擎、模型与花多少钱

## 一、两种引擎，代价完全不同

| | 直连模型 | Agent 子会话 |
|---|---|---|
| 谁在调模型 | 程序自己 | 外部 Agent（编程工具里的助手） |
| 花什么 | 按 token 计费，真金白银 | 你的订阅额度 |
| 设置里的角色模型表 | **生效** | **不生效**（模型由外部 Agent 定） |
| 止烧阈值 | 金额 + token 都有效 | 只有 token 上限有效（金额记账恒 0） |

切引擎：设置 → 引擎与模型 → 点卡片。对下一次运行生效。

## 二、六个角色分别是谁

| 角色 | 干什么 |
|---|---|
| default | 兜底（没单独指定的调用） |
| architect | 设定 / 世界观 |
| outliner | 大纲 |
| writer | 正文写作（最贵，字数最多） |
| checker | 逻辑检查 |
| reviewer | 审稿 |
| polisher | 润色 |

可以给 writer 用贵的、给 checker 用便宜的——这是省钱的主要手段。

## 三、换供应商要小心

**模型名跨供应商不通用。** 换了 provider 却留着旧模型名，运行时会直接 404，而且这个项目对 404 是**报错不回落**——那个角色就哑了。

界面会在切换后提示"模型 X 不在新供应商的清单内"，看到这句就顺手把模型也改掉。

## 四、怎么防止烧穿

「设置 → 预算与止烧」有四个值：单请求输出上限、单轮累计上限、预警比例、是否启用。

超出阈值会熔断，不是提醒你继续。**token 上限是 hermes 模式下唯一有效的止烧手段**（金额阈值在那个模式下不生效）。
