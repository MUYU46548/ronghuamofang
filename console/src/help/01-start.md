# 从零跑通第一章

## 一、准备三样东西

1. **素材**：设定卡放 `materials/raw/`，随手写的碎片放 `materials/original_scraps/`
2. **项目**：书名 / 类型 / 章数（“项目”页一键建，旧项目会自动归档）
3. **API Key**：设置 → 引擎与模型 → 服务商与 API Key → 填入 Key

三项齐了，首页会亮出“开始运行流水线”。

### 素材目录里的“索引”不能当账本

素材目录里如果混着 `00_大纲收束索引.md`、`碎片填充计划.md` 这类**登记表**，它们写的
“共 96 篇 / 9 维齐全”“已登记 24 个日期”可能和盘上的文件对不上。

素材页顶部会直接告诉你差在哪：**索引与实物不一致 → 看明细**，逐条列出“声称 96 篇、
实物 41 篇（差 -55）”“24 个声称日期里有 24 个找不到”。

**以实物为准** —— 流水线读素材时扫的是文件夹里的文件，登记表不参与生产，只影响人看。
登记表没写篇数时就不出现这条提示，不打扰你。

## 二、七个阶段在做什么

| 阶段 | 名字 | 产出 |
|---|---|---|
| 1 | 素材归并 | 素材卡 → 设定集（人物 / 地点 / 势力 / 概念） |
| 2 | 整体大纲 | 全书骨架（卷 / 章分布） |
| 3 | 逐章大纲 | 每章的“核心事件 / 涉及角色 / 功能 / 衔接” |
| 4 | 逐章写作 | 正文 |
| 5 | 逻辑检查 | 缺陷清单（段号 / 原句 / 为什么） |
| 6 | 润色 | 精修稿 |
| 7 | Word 成品 | .docx |

**审批门**只在阶段 2 和 6 设：大纲写完、润色完成，会停在“收件箱”等你确认。阶段 3 不设门，产物在“大纲 / 分章”页签里看。

顶栏页签按用途分三组（组间有竖线分开）：**写作**（流水线 / 章节 / 素材 / 设定 / 大纲 / 分章）、
**审校**（审稿 / 精修 / 审核 / 校对 / 文风）、**系统**（成本 / Agent 提问 / 收件箱 / 项目 / 设置 / 导出）。
判定和“改标准”都在 **章节** 页顶部 —— 详见《判定怎么用》第一节。

大纲页签里还有一块 **“规划四态”**：AI 提的情节方案只会停在 **构想**；你点 **采用** 才进“已采用”，
标 **写进正文** 时要填它落到了哪一章；丢掉的可以 **复活**。
外接 Agent 能提案，但**不能替你点这四个按钮**——采用与否是你的判断。

## 三、两个引擎，选一个

- **直连模型**：程序自己调 API，按 token 计费。设置里的角色模型表在**这个模式**下生效。
- **Agent 子会话**：由外部 Agent（编程工具里的助手）驱动，走你的订阅额度。这时候模型由外部 Agent 定，下面那张角色模型表**不参与**。

切引擎在“设置 → 引擎与模型”的卡片上点一下，对下一次运行生效，不用重启。

## 四、跑起来之后

- 进度看首页的阶段条与“运行日志”；
- **先写几章看看**：阶段 4 那张卡片上有一行“章范围”输入框（单独一行，不在按钮堆里），
  填 `1-3`（或 `1,3`、`1-3,7`）再点运行，它就只写这几章，写完就停。
  **留空 = 把没写完的全写完**。填了只影响“这一轮写哪几章”，不影响断点、不影响已完成的章。
- **审阅台**（章节页右上角那个按钮）：左边列章、中间改正文、右边同时看到“本章出场”
  “这一章本来要写成什么”“七维评审”。改到一半点别的章会被拦住，三个选择是
  **保存并切换 / 丢弃改动并切换 / 留在这章** —— 不会再有改动无声消失。
- **每章多少字**：就在同一个卡片的“每章字数”一行改（下限 – 上限），改完点“保存”，
  下一次写作和校验立即按新口径。**要一章不少于 8000 汉字，就把下限填 8000。**
  总量仍由章数控制：40 章 × 8000 字 ≈ 32 万字。写不到下限会被判不合格并自动打回扩写。
  设置页里同一项也在（“预算与止烧 → 单章字数”），两处是同一个值。
- **“暂停”只暂停显示，不是暂停模型**：它还在一起生成、一起计费。这一轮的提示词在开跑时就
  发出去了，此刻改它不影响这一轮。
- **想中途改方向**：点运行条上的“✎ 插一句”，写一句要求（比如"这一章别写打斗，
  写两个人吃饭时的沉默"）。它**只对下一章生效**，不改大纲、不重写已经写好的章，
  用完自动消失。没在跑的时候不让登记 —— 那种"先存着以后用"的话，到真跑时早过时了。
- 想停，有两个不同的按钮，别按错：
  - **“写完这章就停”**：手上这一章会**完整写完、入稿、计入完成**，然后才停。
    点“运行”从下一章接着写 —— 想收工又不想浪费半小时的活，用这个。
  - **“停止”**：立刻掐断。正在写的那一章半截会存成**残稿**（在“残稿”里可以采纳
    成草稿、也可以丢掉），已写完的章不受影响。
- **AI 在跑的时候你改不了稿**。顶栏会写“施工权：AI 流水线在跑（pid=…）”。
  要改就点“我来改（接管）”：流水线会在**下一章开始前**停手，正在写的那一章会写完，
  已完成的章一张不丢。改完点“改完了，让 AI 继续”把笔还回去，AI 才能接着往下写。
- 某阶段失败：卡片上会出现“重试 / 跳过此阶段 / 回退 / 查看日志”四件套。
- **某一章不满意，重写还是重跑**：章节页每行有两个按钮，动作不一样 ——
  - **重写**：只换这一章的正文（阶段 4）。检查稿、润色稿、评审都还是旧的。
  - **重跑…**：先让你选范围（只正文 / 正文+检查稿 / 正文+检查+润色），
    然后把这一章按范围重算一遍。**别的章一个字节不动**（不会为了 1 章把整本重烧）。
    确认框里会先列出“这次会动哪些文件”；旧产物移到 `data/chapters/rerun_backup/`，
    动手前还会自动打一份整轮快照（备份不了就不动）。
  - 重跑过程中阶段会显示“按范围完成”：那是**如实状态**（只做了你要的那几章），
    不是失败；别的章补齐后自然会变成“完成”。
- **定方向：先选走向，再挑写法**（两个不同的入口，别混）
  - **整本书往哪走** → “大纲”页右上角 **开局方案** → “生成 3 个走向”。三张卡分别给切入时机、
    主线、冲突、基调、前 3 章，并且**每张都写“代价”**（这个方向最容易写崩的地方）。
    选一个点“选这个” → 阶段 2 会按它写整体大纲。不选就按你项目里的梗概走。
  - **这一章怎么写** → “分章”页选中某一章 → 工具栏 **选写作方向** → 选维度（基调 / 视角 / 节奏）
    → “生成方向样例”。三张卡并排，卡片底部给**字数 / 均句长 / 对话句数 / 与其它方向的相似度**，
    用来一眼分辨“同一件事，三种写法”。挑一个（也可以就地改）→ “提交为写作参照（进待审队列）”
    → 去“审核”页批准后，它才会在写这一章时作为参照。
  - 这两个按钮都要调模型：运行引擎设成“只出任务书”（self）时，点它们会直接告诉你
    该切到哪个引擎，不会假装在跑。

## 五、出书之前

阶段 7 之前建议走一遍：

0. **改稿裁定（阶段 5 跑完之后）**：模型检查完**不会直接覆盖你的稿子**。它改的每一处
   会列成一条“原句 → 改后”，你在“审稿”页逐条点 **采用** 或 **保留原文**；全部勾完才合成
   检查稿。没勾完，流水线不会往下走（显示“等待裁定”，点运行也是接着等）。
   一处都不想采用也可以 —— 全点“保留原文”，成品就是你的原稿。
1. **审稿**：逐条决策（接受 / 打回 / 改），打回会让下游产物清掉重跑；
   某一句话想自己动手：段落级精修工作台里选中那一段 → 点“自己改”→ 直接改 → 保存。
   它和“填意见让模型重写”是并列的两条路，不是替代关系；保存前会备份整章，
   旧内容也进段落历史，随时能回退。
2. **校对**：体检报告，缺陷项会告诉你哪段有问题；
3. **判定**：看“这一章行不行”——详见“判定怎么用”那一篇。

最后“导出 → Word 成品”按你选的模板生成 docx。
