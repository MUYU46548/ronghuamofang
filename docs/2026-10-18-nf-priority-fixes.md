## 二、P0（先修这四条，零 token / 极低成本，修完再谈试跑）

### P0-1 中文标点归一化（确定性，零 LLM 成本）★ 最高优先级

- **做什么**：新增 `scripts/utils/text_norm.py::normalize_chinese_punctuation(text)`：
  - 半角 `"` 按开合配对 → `“…”`（成对判定，避免正文里的英文引用被误伤）
  - `'` → `‘’`；`「」『』` → 统一 `“”`
  - `--` / 单个 `—` → `——`；`...` / `。。。` → `……`
  - 汉字之间的 `,;:!?` → 全角；零宽字符、汉字间空格清除
  - 幂等（跑两次结果一致）
- **挂哪**：stage4 落盘后、stage5 落盘后、stage6 落盘后各一次，**stage7 `merge_book()` 前再兜底一次**（成品永不带脏标点）。
- **为什么必须是代码不是提示词**：提示词对这类问题的命中率不稳定，而且**改了也无法验证**；确定性替换可单测、可幂等、可回归。
- **工作量**：约 150 行 + 单测，半天内。

### P0-2 docx 字体：正文 run 显式写 rFonts

- **做什么**：`stage7_convert.py` 的 `_add_paragraph_before()` 给每个 run 写
  `rFonts(ascii=宋体, hAnsi=宋体, eastAsia=宋体)`；字体名走配置 `book.body_font`（默认宋体）。
- **为什么**：不写 rPr 时，`—`/`“`/`”`/`……` 这些字符在 Word 里按西文字体渲染，这就是「破折号字体不对」的直接原因。显式三处同名后，中文与标点视觉一致。
- **工作量**：约 20 行，1 小时内。

### P0-3 单章字数：可配 + GUI 入口 + 判据收紧

- **做什么**：
  1. GUI「设置」页新增「单章字数区间」（走既有 `set_section_scalar` 定向改写 + 备份 + 回读校验）；
  2. 出厂默认从 `[2000, 5500]` 提到 **`[5000, 9000]`**（你之前定的口径：单章 5000~15000、常态 ~8000）；
  3. 扩写触发从「低于下限 60%」改为「**低于下限即触发**」；
  4. `quality_checklist` 把「低于下限」列为 FAIL（现在只在 `verify_chapter` 的续跑判据里卡，收尾门禁不卡）。
- **工作量**：小-中，约半天。

### P0-4 碎段：写进提示词 + 保守判据

- **做什么**：
  1. `prompts/stage4_writing.md` 前缀区加一条段落规则（注意：加在 `---` 之前的**逐字不变区**，不影响前缀缓存）；
  2. `verify_chapter.py` 加结构判据：短段（≤12 字）占比 >30% **且**均段长 <20 字 → 判「段落过碎」，进 warn（触发精修），**不作硬失败**。
- **为什么保守**：`verify_chapter.py` 里已有 2026-09-20 的定标记录——中文小说单句成段是**合法写法**，健康章节均段 19.2~47.6 字、对话密集章短段很多。判据必须避开误杀，否则会变成「反复重写烧钱」的新坑。
- **工作量**：小，2-3 小时。

## 三、P1（决定质量上限，P0 之后立刻做）

### P1-1 让「模仿」真的有东西可模仿

- `style_reference` 目前为空 → 把它变成**必填向导**：设置页首启引导「选 1-2 篇你认可的原文」，或从 `materials/` 自动登记；空值时 GUI 显示警示（现在是静默降级）。
- 设定集**内联**：当前只给 `setting.json` 路径，agent 读多少、读哪条不受控 → 改为按本章「涉及角色」把相关条目**直接内联进提示词**（角色卡已内联，地点/势力/时间线同样处理）。
- 本批新增的 `chapter_samples` / `branch_samples`（选写作方向）需要做**回读校验**：生成的样例文与注入后的正文做风格相似度比对，注入无效要能看出来，而不是「加了就当有用」。

### P1-2 把「读起来烂」变成可拦截的判据

- 现在的 `quality` 是模型自评 + 注释，没人复核 → 加**跨章离群检测**（字数 / 短段比 / 对白占比 / 标点异常 / 句长方差），离群章自动进 `batch_refine` 队列，报告落 `data/outline/`。
- `proofread_after_polish` 默认 `false` → 建议**默认开**（它是只报不改的确定性检查，零 LLM 成本），报告进 GUI 校对面板。
