## 二、完整声明（设置页可随时回看）

### 1. 你提供的作品

- 拆解功能处理的是**你本机上的文件**。绒花墨坊不会把作品原文上传到自己的服务器
  （绒花墨坊没有这样的服务器）。
- 拆解完成后的**原始文本不保留**；`materials/style_profile.json` 只存统计结果
  （章长分布、对话占比、句长分布、钩子位置等）。
- 如果你选择"抽取片段做 few-shot"，被抽中的片段会随写作任务一起发给
  **你自己配置的大模型服务商**——这是该功能的必要组成部分，不是可隐藏的行为。

### 2. 大模型服务商

- 绒花墨坊不运营大模型，不参与模型服务商的数据处理。
- 你配置的 API 服务商（OpenAI / Anthropic / DeepSeek / 智谱 / 通义 / Kimi 等）
  对输入内容是否保留、是否用于训练，**以其隐私政策与服务条款为准**。
- 绒花墨坊**不做担保、不做承诺**，也无法代表服务商作出任何承诺。
- 如需完全不外发数据，请使用本地模型（Ollama / LM Studio 等）。

### 3. 责任边界

- 你是否拥有导入作品的合法使用权，由**你自行判断并承担全部责任**。
- 绒花墨坊不审查、不校验、不担保导入内容的权属。
- 因使用本功能引起的任何争议、索赔或损失，由使用者自行承担。
- 本功能**不提供**规避技术保护措施（DRM）、不提供整本复制与再分发能力。

### 4. 同意与撤回

- 未点击"我同意"不得使用本功能。
- 你可以随时在设置页撤回同意：撤回后本功能的入口关闭，已有的
  `style_profile.json` 保留与否由你决定（提供"一并删除"按钮）。
- 撤回不影响撤回前已经完成的操作。
