## 2. 一个段群的 68 步：正文只占输出 token 的 15%

stage4 第 1 章第 1 群（17:05，880 秒，74,628 输出 token，落盘 1,482 汉字）逐 step：

| 步 | 做了什么 | 输出 token |
|---|---|---:|
| 1–19 | `read` 任务书 → `Get-ChildItem` 逛工作区 → 读 `prompts/*.md` → 读 `scripts/*.py` → 读 setting.json | 37,021（49.6%） |
| 20 | 第一次 `write`：写出本章群正文 1,482 汉字 | 11,309（15.2%） |
| 21–63 | `cd workspace; ...` 数汉字 / 查标点 → `edit` 改段落与标点，反复 40 余次 | 约 24,500 |
| 64–68 | 再读一遍最终文件 → 汇报 | 1,780 |

同型的探索在别的阶段一样存在：

- 阶段 2：第一次 `write` 之前 **42 步 / 68,664 token**（占该会话输出的 52%）；
- 阶段 3：83 次 `pwsh`，第一次写之前 35 步；
- 阶段 1：66 次 `read`、23 次 `pwsh`（其中一次 `write` 的参数串 75,311 字符，写出的 setting.json 最终 126 KB —— 这一次是有效工作）。

模型不是“在写”，是在**当代码助手**：先摸清仓库、再自检字数、再改到过检。墨坊在模型返回后本来就会用 `is_chapter_complete` 做确定性校验，模型这一遍自检是重复劳动。

## 3. 三条乘数，不是一条瓶颈

| 乘数 | 对什么生效 | 证据 | 量级 |
|---|---|---|---|
| ① 整章拆 6 群 | 每章的调用次数 | 工作区 `chapter.enhanced_mode: true`；6 章 × 6 群 = 36 次会话 | 章级 ×6 |
| ② agent 探索 + 自检 | 每次调用的输出 token | 单群 85% 输出不是正文：37k + 24.5k 对 11.3k | 调用级 ×5–6 |
| ③ `reasoningEffort`（DSH profile） | 每次调用的思考量 | `~/.dsh/profiles/headless/cordis.patch.yml:14`；**这是 DSH 的设置，墨坊不传、不改、不建议** | 不计入墨坊杠杆 |

调用级两个乘数叠起来约 ×10（正常中文约 2–3 token/字，实测 50 token/字），章级再乘 6 次调用，就是实测的 **15 分钟/群**；按 6 章 × 6 群推算 **9 小时/本**。

## 8. 复现（只读，零 token）

```python
import zstandard, json, pathlib, collections
root = pathlib.Path.home() / ".dsh/sessions/--C-Users-muyu-AppData-Roaming-~7ED2~82B1~58A8~574A-workspace--"
for d in sorted(root.glob("session-*"), key=lambda p: p.stat().st_mtime):
    with (d / "session.v4.jsonl.zstd").open("rb") as f:
        raw = zstandard.ZstdDecompressor().stream_reader(f, read_across_frames=True).read()
    ev = [json.loads(l) for l in raw.splitlines() if l.strip()]
    steps = [e for e in ev if e["type"] == "step/start"]
    calls = [e for e in ev if e["type"] == "tool/call"]
    asst = [e for e in ev if e["type"] == "assistant/message"]
    think = sum(len(b.get("thinking") or b.get("text") or "")
                for a in asst for b in (a["data"].get("message", {}).get("content") or [])
                if b.get("type") in ("thinking", "reasoning"))
    out = sum(int((a["data"].get("usage") or {}).get("outputTokens") or 0) for a in asst)
    print(d.name[-8:], len(steps), len(calls), think, out,
          dict(collections.Counter(c["data"].get("name") for c in calls).most_common(4)))
```

注意：`ZstdDecompressor().decompress()` 只解第一帧，会得到 213 字节的会话头；必须用 `stream_reader(..., read_across_frames=True)`。
