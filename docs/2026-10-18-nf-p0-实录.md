### 字体（`stage7_convert.py`，+117 行）

- `_style_font_map(doc)`：读**模板自己声明**的字体，沿 `basedOn` 链解析
- `_apply_cjk_font(run, font)`：逐 run 写 `ascii` + `hAnsi` + `eastAsia` 三处 + `hint="eastAsia"`
- 正文用 `Normal` 的 eastAsia，章标题用对应 `Heading N` 的 eastAsia

**为什么不能硬编码宋体**（你点破的那条）：实测模板里正文=宋体、章标题=黑体、引用/卷首诗=楷体，三套并存。硬编码宋体会把章标题一起刷掉，等于用一个 bug 换另一个。

**为什么要三处都写**：Word 对 U+2014（—）、U+201C（“）、U+2026（…）这类**通用标点**按 `ascii`（西文字体）渲染。旧实现只靠样式继承，样式里 `eastAsia=宋体` 而 `ascii=Times New Roman` —— 于是汉字是宋体、破折号与引号是 Times New Roman，这就是你看到的「破折号字体不对」。

### 提示词（5 份）

`stage4_writing` / `stage4_expand` / `stage4_refine` / `stage4_refine_paragraph` / `stage6_polish` 各加一节标点与段落硬性要求，含你给的三句错误示范（老师留下的。/七锁回环。/这是老师的手笔。）。

写作模板的规则加在 `---` 分隔线**之前**的逐字不变区，不破坏前缀缓存。

## 二、顺带修掉的两个**通用缺陷**（不是本批引入的）

### 1. `config_io._block_range`：块序列残留

把 `target_words:` 从块序列改成流式列表时，旧的 `- 2000` / `- 5500` 会残留成孤儿 → **整份 YAML 解析失败**。

根因：YAML 块序列的 `- 2000` 与所属键**同缩进**（不是更深一层），而 `_block_range` 按「缩进 <= 键缩进即块结束」判，块被判成空块。

写后回读能拦住（fail-closed），但文件此时已经写坏，只能靠备份回退。

### 2. 同一函数的反向回归（我自己引入，当场抓到）

修完上面那条后，`_block_range` 范围变大 → `_apply_one` 的 `del` 把**块尾下一个键的说明注释**也删了：一次写 5 个键时 245 → 225 行，20 行说明文字消失。

回读校验查不出这种损坏（值都对，只是注释没了）。现在 hi 停在最后一个非注释行。

两条各有回归断言：`test_config_io.py` 的【4b】【4c】，53/0。

### 3. `text_norm` 的三个自身 bug（首次验收当场抓出）

| bug | 症状 | 修法 |
|---|---|---|
| 句中引号漏判 | `程砧说的"想通"` 前一字符是汉字，被「前一字符是否为开符号」的启发式判成不动 —— 真实产物 01/03 章残留的就是这种 | 改**行内开合交替**：偶数个严格交替，奇数个保留最后一个为孤儿不硬造配对 |
| 半角逗号映射键写错 | `KeyError: ','` 直接崩 | 修键 |
| 破折号误伤英文 | `--flag`、`3-5` 被转成 `——` | 破折号只在**汉字/中文标点语境**下转换 |

单引号同样改成「候选位成对处理」：候选不足 2 个一个都不动（半开的 `‘嗯'` 比不改更糟）。

## 七、二号测试用例：《炭城纪》（10-19）

### 为什么还要一套

一套夹具只能证明「第一套素材配套」。提示词、抽取规则、模板都可能在那一套专名上
**恰好成立**——换名字就露馅。所以把工作区那批《雾港纪年》旧卡改皮成**第三个虚构宇宙**
（《炭城纪》），落成 `tests/fixtures/sample-book-2/`：同样 19 张卡、同样自洽、零重复专名。

**它不是出厂样例**：不进安装包、不在 GUI「出厂测试项目」里出现，只服务回归测试与手工试跑。

### 怎么改的（可复算）

按**长度降序**的映射表做机械替换（`雾港纪年→炭城纪`、`潮神→窑主`、`白蚀→盐蚀`、
`潮崩→窑崩`、`鲸民→陶民`、`织术→陶律`…），文件名同步。两个坑记在这里：

1. **包含关系**：`潮汐穹顶→窑腔` 会先被 `穹顶→窑腔` 改成 `窑腔穹顶`、再变成
   `窑腔窑腔` —— 用占位符 `\x00DOME\x00` 延后落地。
2. **语义残留**：`白化` 不在词表里，但它属于旧宇宙的描述（要对应「盐化」）——
   只换名词不换动词，卡读起来仍然别扭。

`test_sample_book_2_coherence.py`（**11 断言**）钉住：卡数、大纲实体全部有落点、
**前两个宇宙的词一个都不许残留**（含《雾港核心》的 沈砚/程砧/机关术）、脱敏声明、
首行标题、无绝对路径、**文件名与卡内专名一致**（改名不得只改一半）。

### 顺带修掉的假红：`test_leak_scan` L7

上轮记录的说法是「探针词命中的文件在 allow 豁免名单里」——**不是真因**。
实测：该词在**56 个文件、155 处**命中，而 `leak_scan` 默认 `--max-print=50`，
按路径排序先被 `AGENTS.md`（豁免文件）占满 → `.bat` 文件**扫到了但没打印**，
断言却建立在被截断的终端输出上。

修法：取探针时排除 allow 文件；端到端改用 `--json` 取**全量 hits** 断言。
教训与门禁本身一致：**判据不能建立在被截断的输出上**。
