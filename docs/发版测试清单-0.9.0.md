# 发版测试清单 · v0.9.0（2026-11-08）

> 装在**真实安装环境**上测，不要用 `npm run dev`。开发模式有源码树与 `.venv` 兜底，
> 装完才不会的那些问题（路径、运行时、种子刷新）只有安装版能暴露。
> 每条都写清“怎么点”“算通过”“失败了给什么证据”。

## A. 安装 / 升级（必做，约 5 分钟，不需要模型）

1. 双击 `ronghuamofang-console-setup-0.9.0.exe`。
2. **安装目录保持向导显示的目录不变**（覆盖旧版），下一步到底。
3. 启动后确认：
   - 窗口正常出现，无黑窗、无控制台闪烁；
   - 顶部/关于里版本是 **0.9.0**；
   - 左侧“项目”页，你现有的书还在，章节数/进度与升级前一致。
4. 工作区代码已刷新：打开 `%APPDATA%\绒花墨坊\workspace\.seed-version`，内容应为 **90**。
   （这一步看的是“安装包里的新脚本真的铺进工作区了”，不是版本号自报。）

**失败证据**：截图 + `%APPDATA%\绒花墨坊\workspace\logs\` 下最新日志。

## B. 多库同时读（必做，约 10 分钟）

1. 设置 → 风格与提示词 → 知识库。
2. “库在哪”填第二个库的根目录 → **加入我的库**。
3. “我的库”里应该出现两条：当前库 + 刚加的库。给新库点**启用**。
4. 点**检查同名冲突**：
   - 算通过：列出“同名 X：用 A 的，忽略 B 的”；没有同名条目则明说“没扫到同名条目”；
   - 失败样子：点了没反应、报错、或列表里根本没有刚加的库。
5. 给新库点**停用**，再点检查：冲突应减少（那条库不再参与）。
6. 点**改成单库模式**：标题变成“单库模式”，再点回“改成多库同时读”。

**重点看**：停用/启用后，`materials/`、书稿文件**一个都没变**（只改扫描范围）。

## C. 酒馆资料导入（约 5 分钟）

1. 素材 → **导入酒馆资料**，选一个真实的 SillyTavern 角色卡（`.png` 或 `.json`），
   有世界书 JSON 的话一起选。
2. 算通过：
   - 素材列表新增 `角色名（酒馆角色卡）.md` / `世界书名（世界书）.md`；
   - 打开能看到“设定 / 性格 / 开场 / 内嵌世界书”这些小节；
   - 再导一次同名文件：明确提示“同名素材卡已存在（不覆盖）”，原文件不变。
3. 失败样子：按钮没反应、导入后素材为空、或把已有素材覆盖了（这是红线，立即报）。

## D. 段落快捷改法（需要真实模型，约 10 分钟）

1. 章节 → 打开一章 → **审阅台**（或编辑器的“段落批注”）。
2. 点正文某一段 → 右侧“已选第 N 段”。
3. 依次点 **润色 / 扩写 / 改成对话 / 往下续**：
   - 算通过：意见被填进输入框，**此时不应有任何费用**（不点“只改这一段”就不发请求）。
4. 点“让 AI 只改这一段”，等返回：
   - 算通过：**只有这一段**变了，其余段落逐字不变；字数/内容合理；
   - 失败样子：整章被重写、其他段被改动、或报错。
5. 不满意就到 章节 → 历史，确认能回退。

## E. 判定分类表 + 亲手勾一章（约 15 分钟，勾选不花 token）

1. 章节 → 判定 → **改标准** → 找到 **J22 · 事件分类表**。
2. 加一类（例如“时间”，例子写“入秋了 / 过了一年”），保存：
   - 算通过：提示生成了新版本号；刷新后该类还在。
3. 回单章判定 → 勾选“这一章发生了几件事”：
   - 勾一条 → 选刚加的“时间” → 填证据句 → 保存；
   - 算通过：保存成功，判定摘要里“认定 N 件 / 计入 N 件”跟着变。
   - 失败样子：分类里看不到“时间”，或保存时报“分类不在事件分类表里”。
4. **放行一次**：按你的判断给这一章一个结论（合格/要改），这一步只有你能做。

## F. 字数达标（需要真跑，建议 1–2 章）

1. 流水线 → 选“阶段 4 逐章写作”，跑 1–2 章（真实模型）。
2. 跑完看 章节 → 润色稿 的字数徽标：
   - 算通过：每章**汉字数 ≥ 4000**（只数汉字，不含标点）。
3. 不达标就记录：章节号、汉字数、当时的 `每章字数` 设置（连同上限）。

## G. 安装版里的外部 Agent（约 10 分钟）

1. 设置 → Agent 接入 → 按页面“复制配置/启动提示词”贴给 Hermes。
2. 算通过：对方能列出 `nf_*` 工具并成功调用一次只读工具（如 `nf_get_state`）。
3. 失败样子：连不上 / 工具列表为空 / 调 `/state` 报 404 —— 记录是**垫片层**还是**服务层**报错。

## H. Word 成品（约 5 分钟）

1. 流水线 → **Word 成品**（或导出）。
2. 打开 docx 确认：书名/作者已填、章标题层级对、目录域在、页边距与模板一致。

## I. 卸载/重装（约 3 分钟，重要）

1. 卸载 → 确认 `%APPDATA%\绒花墨坊\workspace` 还在（书稿/素材/配置都在）。
2. 重装 0.9.0 → 启动，书还能打开、能继续写。

## J. 可选（有风险，别在真书上做）

- 出厂预设真机跑一本：会把当前项目**归档**再铺样例素材。确认你愿意再做。
