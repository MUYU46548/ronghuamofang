**这是 DSH profile 的设置，墨坊不传、不改、不建议。** 作者 2026-11-27 两次纠正：
既不要把它降档，也不要把 `max` 固化成墨坊的规则 —— 要改就改 DSH 自己的配置，
墨坊跟着走。任何“墨坊侧降思考强度”的方案都不再做。

同一层还有两个事实：

- `cordis.yml` 自己是空数组 `[]`，注释写着整棵树是 "composed as patches"：
  `package.json` 的 `dsh.profile.bundles` = `@deepseek-ai/dsh-base` + `dsh-ronghuamofang` +
  `@deepseek-ai/dsh-headless`，再叠 `cordis.patch.yml`。**工具是 base 里的插件，不是本体**，
  所以能摘——但 base 包的确切位置没找到（多半打进 asar），插件 id 拼写待确认。
- 墨坊不参与这一层（`DshClient` 只发任务书、不传模型名）。

⚠️ **这是全局配置**：司天、方寸同一套 headless profile 共用。改之前要知道影响面。
