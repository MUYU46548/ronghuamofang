## 一、结论（先看这段）

1. **最大风险不是功能少，是"假绿灯"。** 整套判据（七维/审美/记忆/卷弧/文体）至今
   **没有一次真模型跑完整本书的证据**，全部是夹具证据。夹具能证明"接线对"，
   证明不了"模型会按格式输出"。
2. **本轮抓出 4 处"配了不生效 / 界面说假话"**（已修，见第二节）。这类问题的共同形态：
   代码写了、单测绿了、界面还告诉你它生效了，但实际没接上。
3. **功能缺口按"会不会让你拿到假结论"排序**，不按开发难度排序（第三节）。

## 二、本轮已修（4 处，都有断言）

| # | 问题 | 形态 | 后果 |
|---|---|---|---|
| 1 | 文体只能手改 `config/project.yaml` | GUI 没有入口 | 对不写代码的用户等于"散文功能不存在" |
| 2 | stage5 提示词硬写「七维 + 五问」 | 校验侧标 N/A，提示词没裁 | 散文每章白烧约 600–800 输出 token，账本里留下模型为凑数硬编的证据 |
| 3 | `writing_form` 的 `volume: False` 没人读 | 配置项没消费方 | 散文照样分卷、照样调模型生成卷纲；`describe()` 还打印"不做分卷滚动" |
| 4 | `style_wired` 用"回落正文非空"判断 | 回落 ≠ 接入 | 书信/单元体在界面上显示"已接入写法指导"，实际用的是叙事提示词 |

修法：
- 新增 `GET/POST /config/form` + 设置 → 提示词 →「文体」下拉（非法值**拒写**，写后回读校验）。
- 新增 `writing_form.review_scope()`：按文体生成评审提示词，**连 JSON 示例一起裁**
  （示例里出现七维，模型就会照着写七维）。叙事 7 维 + 5 问，散文 1 维 + 4 问。
- `volume_plan.ensure_window/ensure_volume` 按 `form` 早退，不调模型。
- 新增 `writing_form.style_files_exist()`：判**文件是否存在**，不看正文是否为空。
- 断言：`test_writing_form.py` 55 → **81**；`nfctl test` 128 / 128（另有 1 条护栏抓到
  我写的裸相对路径，已修）。

## 三、还没补的（按"会不会给你假结论"排序）

### P0 — 会给出假的"检查通过"

| 缺口 | 为什么危险 | 补法（成本） |
|---|---|---|
| **真机全链零证据** | 8 个阶段从没在真模型上跑完一本书。所有新判据只有夹具证据 | 用出厂预设跑一本 5 章小书，产物与成本落 `docs/evidence/`（见第四节） |
| **七维 JSON 合规率未知** | 模型不吐 JSON / 吐错格式 → 账本为空；`gates.review_ledger` 默认 `warn` → **只告警不拦**，你会看到"阶段完成"，实际什么都没查 | 同上一次真机跑即可测出；若合规率低，再决定是否改 `block` 或加"格式修复一轮" |
| **散文文风块未经真实样本校准** | 我按常识写的"观察与感受"版提示词，没在真实散文上验证过。可能出现"判据对了、写出来还是小说腔" | 先写 2–3 篇你自己满意的散文当范文，跑一次再看 |

## 四、成本预警（按你的实际项目估）

| 项 | 量级 | 说明 |
|---|---|---|
| 3 章项目跑一轮 stage1–7 | 与章节数成正比 | 你当前项目 `chapters: 3`，是试跑的好规模 |
| 每章 stage5 多出的评审输出 | **约 600–800 token/章**（叙事）；散文裁后约省一半 | 12 条举证 JSON vs 原来的自由文本报告 |
| **重跑才是真正的成本** | 每章输入可达上万 token（范文 ≤6000 字 + 记忆块 + 设定） | 任何"判失败 → 重跑"都是成倍烧钱 |
| 建议节奏 | 先跑 5 章 | 看账本合规率与同质化指标，再决定是否跑长篇 |

**省钱的三个开关（都可关）**：
- `book.style_reference_max_chars`（范文注入上限，默认 6000，**每章都要付**）
- `chapter.rolling_volumes: 0`（关分卷滚动）
- 散文/随笔：不分卷、不评无关维度（本轮已生效，token 直接降）

## 六、下次自查的口诀

每加一个配置键，问三句：
1. **谁读它？**（没有消费方 = 假功能）
2. **不生效时，界面会不会说生效了？**（`describe()` / `style_wired` 都栽在这）
3. **判据是"存在"还是"有内容"？**（空值、回落值都会骗人）
