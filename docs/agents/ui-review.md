## 三个已踩过的坑

| 坑 | 现象 | 正解 |
|---|---|---|
| **四列卡片** | 审阅台（三栏）内联 `ChapterEditor` 时，编辑器自带 `.ce-side` 又占 240px，与审阅台右栏并排成两列卡片 —— 用户看到“一堆重叠的卡片” | 内联时侧栏只在 `mode === 'paras'`（段落批注）出现；编辑模式正文吃满宽度 |
| **组名被当页签** | 给 `.tab-group` 加“写作/审校/系统”小字，读起来像多出三个页签 | 分组语义放 `aria-label`，界面上靠底色/间距表达，不新增文字 |
| **切章丢稿** | 改到一半点“下一章”直接换章，改动无声消失（顶部只有一行灰字） | `ChapterEditor` `defineExpose({ dirty, save })`；父组件切章前拦：保存并切换 / 丢弃并切换（标红）/ 留在这章 |
