# 绒花墨坊 0.9.15 发布说明

## 这一版是什么

这一版主要解决两件事：**写一章更直接**，以及**花超了之后更容易恢复**。

- **阶段 4 写正文改成一次生成整章**：模型不再一边写一边翻目录、读脚本、反复改文件，
  而是拿到这一章需要的资料后直接写完整章，由程序保存。正常情况下的等待时间和
  token 消耗都会明显下降。
- **单章预算**：一章（包括分段写和重试）累计超过上限会自动停下，不会一本书还没写完
  就把额度烧穿。
- **恢复更清楚**：暂停时界面会说明是哪条上限到了、建议调哪一个；点“恢复并继续”
  就会清掉暂停状态并从当前阶段接着跑，不需要自己去改文件。
- **一批“点了没反应”的修复**：大纲提交精修、AI 修订节点、生成 3 版、恢复运行，
  现在都会给出明确结果或失败原因，不再无限转圈。
- **素材页说人话**：不再用“结构化卡片 / 原始碎片”考用户；跑阶段 1 前会先列出
  “会读哪些、跳过哪些”，放错位置能当场看出来。
- **进度能回答“还要多久”**：整本进度、当前章/段、按当前速度估算的剩余时间放在一起，
  不再只有几个互相对不上的百分比。

## 怎么升级

- 用收到的 Windows 安装包覆盖安装即可，不需要先卸载旧版。
- 原有的书、素材、章节、设定、提示词都会保留；升级只替换程序文件。
- **不需要在绒花墨坊里填 API Key**。模型与账号由 DSH 负责：在 DSH 桌面端登录，
  或在 DSH 的配置里准备好凭据即可。
- 如果你在 DSH 里使用“绒花墨坊”面板，需要同时安装插件 **dsh-ronghuamofang**；
  只用桌面端写作的话，不装插件也能正常跑。

## 隐私与默认行为

- 书的素材、大纲、章节、设定和导出成品都保存在你自己的电脑上，不会上传到我们的服务器。
- 只有调用模型时，必要的写作资料会发送给你在 DSH 里配置的模型服务商。
- 审批门默认保持开启：每个关键阶段完成后会停下来让你确认，不会一路自动跑到底。
- 成品导出默认不包含半成品章节；没写完的章不会混进 Word。

## 已知限制

- **界面组件统一还没有全部完成**：这一版仍有部分页面使用旧样式，外观不完全一致；
  组件基座迁移还在继续，不影响写作和导出。
- **单章耗时受模型服务商和网络影响**：这一版减少了模型自己翻文件、反复自检的开销，
  但无法承诺每一章都在固定时间内完成。
- **只提供 Windows 桌面版**，暂不支持 macOS 和 Linux。
- **首次使用仍建议先跑一章试试**：确认 DSH 已登录、模型能正常返回，再开始整本。
- 这一版没有改变“审批门需要你确认”的设计；想让流水线继续，仍需在界面上点确认。
