## 二、这 11 个书档暴露的真问题

`潮汐档案/state/agent_audit.jsonl` 只有 **11 行**，逐行是：

```
/stage/1/run  /stage/2/run  /stage/3/run ×2  /stage/4/run  /stage/5/run
/stage/6/run  /stage/7/run  /stage/8/run   /stop ×2
```

**六本书，每一本都是"跑完 → 看结果 → 废掉"，中间没有一次逐章修改的记录。**

这和 `产线` Q6 的原话对得上：瓶颈是**改不动（交互）**，产能不是问题。
把两件事连起来读，结论只有一句：

> 不是生成得不够多，是**从来没有任何一本被改到什么程度过**。
> 产能已经过剩，消化能力是零。所以第七本跑出来，大概率还是第六本的样子。

这不是模型的错，也不是"再多加几个生成功能"能解的。**要加的功能，必须加在"让改这件事真正可行"上。**

## 三、该加的功能（按"让第七本不同"排序）

### 1. L2“一句话改一段”补到能真正用 —— P0

产线已定 L2 先做。这里只补**最小规格**，照 Sudowrite 的五个组成部分对表，墨坊缺三件：

| 组成 | Sudowrite | 墨坊现状 | 要补到 |
|---|---|---|---|
| 预设档 | 7 档（润色/更短/更多描写/Show not Tell…） | `QUICK_EDITS` 四档，**只把话填进输入框、不发请求**（`console/src/ChapterEditor.vue:78-86`） | 点了就发 |
| 多候选 | 默认出 2 条 | **1 条** | 默认 2 条，可调 |
| 差异标色 | 字符级标紫 | **段落级**（`console/src/diff.js`） | 字符级 |
| 显式采用 | 点 insert 才替换 | 有 | 不改 |
| 上下文交代 | 卡顶斜体 prompt + chiclets | **没有** | 卡上说清这次带了什么 |

判据（可量化，不用猜）：**作者改一章的时间 < 手写同章的三分之一。**
做不到就说明 L2 没做完，不许拿"功能已上线"结项。

### 2. 三态对照分析器 —— P0，零 token

盘上已经躺着 `raw / checked / refined` 三态。潮汐档案砍掉 7,000 字的差额，就是
**"审稿判定为废话"的实证清单**——比任何提示词都准，而且是现成的。

做成三件事：
1. 逐段对齐三态，标出哪一段在哪一步被删；
2. 删掉的段落按类型归类（解释性旁白 / 万能修饰 / 重复 / 离题 / 与设定冲突）；
3. 归类结果反哺两处：`utils/ai_voice.py` 的阈值、`prompts/stage4_*.md` 的写法指导。

**为什么排这么前**：它零模型调用、数据已在盘上、做完立刻有产出。
等于把六本书的学费换成教材。**现在这六本的经验正在硬盘里烂掉。**

### 3. 句法级“读不懂”检测 —— P1，零 token

`产线` Q10 已定判据：**一句话必须一遍读懂，读不懂就是缺陷。**

但 `utils/ai_voice.py` 现有五类（解释性旁白 / 万能修饰 / 对称句式 / 套话 / 金句结尾）
**全是腔调层，没有一条判可读性**。作者给的三条真例子它一条都抓不到：

```
今晚不用消化这个。睡。
两条腿都已有主
包括这条在内，也是话。
```

这三句是病句（主语缺失、动词悬空、连接断裂），不是俗套。
第二条判据建议加 `unreadable_sentence`：主语缺失 / 动词悬空 / 连接断裂 / 指代无对象。
**这三句直接当校准样本**，跟现有 `examples/samples/ai_voice/` 一个路子。
纪律不变：只报不改，命中是证据不是结论。

### 4. 废稿段落池 —— P1

11 个书档的 `refined/` 里有大量合格段落。现在废稿等于垃圾，删档即清零。

做成可检索的段落池（按人物/场景/情绪打标签），新书写作时作为候选素材召回。

**一条前置**：复用旧段落是否符合你的写作观，需要你拍板。
反方理由很硬——段落脱离原语境会带旧书的腔；正方理由是六本书里一定有好东西。
**没拍板不动手。**

### 5. 结构层“章职能”判断 —— P2

七维评审管**正确性**（逻辑无懈可击的干稿能拿满分），审美五问管**好不好看**。
中间空着一层：**这一章有没有干成它该干的事**（推进主线 / 立人设 / 埋钩子 / 转节奏）。

章大纲六字段有"核心事件/小目标/钩子"，但**没有一处回头校验"写完的正文兑现了没有"**。
这层判断不需要模型品味，只需要对照大纲（零 token 可做初筛，模型复核可选）。
