# 概念：清算

## 基本信息

清算（Liquidation）是绒花世界观中，宇宙对"过于集中的高维信息操作"所做出的原生响应。它并非任何神明、文明或势力的意志产物，而是一条类似重力的客观环境约束——不判断善恶、不区分动机、不豁免任何身份。

当单位时空内累积的高维信息操作浓度（即侵蚀度）突破其所在世界的污染阈值，宇宙便以一次"清算"作为回应，例如局部物理定律发生不可预测、不可逆的失效。这种失效在可观测层面表现为我们称之为天灾的现象。除此之外，还有可能发生以下灾害：强力怪物在天灾中生成、大范围的自然灾害、超出常理的宇宙空间剧变、具有传染性的侵蚀物体降临。天灾的形式并不唯一，多种负面事件可能接连发生。

## 侵蚀-清算框架

本框架为《示例书目》及相关前置作品的核心宏观设定。所有相关要素均由此单一规则自然生长，不依赖额外假设。

### 底层规则

- 宇宙会对"过于集中的高维信息操作"产生响应，表现为侵蚀度（Erosion Index）的累积。
- 侵蚀度突破所在世界的污染阈值时，触发清算，其可观测形态即天灾。
- 该规则不判断善恶、不区分动机、不豁免任何身份。它只是一条环境约束，像重力一样客观存在。

### 延伸内容

魔法与传统科技共享同一套底噪。清算的触发不限于魔法。任何足够复杂、足够密集的信息操作——无论是魔法还是高精尖科技——只要在单位时空内达到一定浓度，都会累积侵蚀。区别仅在于速率：

- 魔法：侵蚀累积速率极高。
- 传统科技：侵蚀累积速率极低。
- 二者共享同一套"底噪"，不存在"零侵蚀"的纯净路径。

这一延伸带来两个结构性后果：

- "科技替代魔法"并非完美解，而只是缓释方案，把高速率侵蚀换成低速率侵蚀。
- 前置作品中"科技错误发展同样触发清算"的现象，在此获得统一解释：科技只是让过程变得更慢，无法从根本上免疫。

## 与天灾的辨析

清算与天灾是同一事件的两个层次，而非两种独立灾难：

- 清算是机制与过程层：指宇宙在侵蚀度突破阈值时执行的响应或触发本身，强调因果与宇宙账本。
- 天灾是现象与结果层：指清算发生时，在可观测现实中呈现出的"非常规"灾难，如引力异常、光速波动、维度褶皱、时空崩解、怪物生成、生态突变。

换言之，天灾是清算的外显形态，清算是天灾的内在机制。每一次天灾都对应一次清算事件；而"清算"一词侧重于"宇宙为何响应、如何响应"，"天灾"侧重"世界遭遇了什么"。在侵蚀的语境中，三者构成上游—阈值—事件的完整链条：

高维操作导致规则损伤 → 侵蚀度累积（污染值增加） → 是否突破临界阈值？ → 宇宙清算协议（被动响应） → 现实扭曲 → 天灾爆发（违背常理的巨灾）

## 文明应对机制

绒花帝国在漫长试错中逐渐发展出经验性应对体系，创建或主导了相关组织，如正弦司与魔法使自律委员会。

- 魔法许可制度：由正弦司执行。分级执照对应不同操作权限；每次施法留痕，计入个体"侵蚀贡献账户"；年度复核，超限者降级或吊销。
- 审查与监控：全境场波动监测网络实时追踪异常能量聚合；重大施法须提前报备"窗口许可"；施法后提交"残余场影响报告"。审查只针对"浓度"，不针对"意图"。
- 科技替代路径：大众以科技产品满足生活需求，主动远离魔法。但科技替代有上限（如星际航行、超大规模能源转换），完全放弃魔法等于放弃了诸多便利于可能。
- 跨界魔法使群体与自律委员会：来自其他世界的魔法使携带不同侵蚀速率的魔法系统；魔法使自律委员会作为自我管理机构，承担侵蚀风险评估与内部施法规范，并与正弦司双边协商。
