# 构造样本（不是任何真实书稿）

这些文件是**夹具**，2026-11-07 为三件“等真实样本”的欠账补的：

| 目录 | 用途 |
|---|---|
| `forms/` | 书信 / 单元 / 散文三种文体的最小样本，用来校准写法指导（`prompts/style/*.md`）与判定口径（N/A 是否真的生效） |
| `ai_voice/` | 一对“AI 腔 / 人写”对照样本，用来校准 `utils/ai_voice.py` 的确定性扫描 |

三条纪律：

1. **人物、地点、事件全部自造**，与 `materials/`、`data/`、`Temp/` 里的任何真实素材无关
   （发布树专名只能取自虚构侧，见 AGENTS.md《发布树卫生》）。
2. 样本只用于测试与人工对照，**不参与任何书的流水线**。
3. 样本短是刻意的：它们要能一眼看完全文、判断“这段像不像人写的”，不是拿来当范文模仿。
