# 出厂预设 · 磨坊记（脏输入 · 内部用）

**验什么**：stage1 的容错与冲突检测——文件名乱、无卡类型后缀、素材自相矛盾时，
系统是**报冲突**还是**静默挑一个用**。

**规模**：4 章 × 4000-6000 字，奇幻/乡土。

> ⚠️ 本套 `hidden: true`，**不进 GUI 预设列表**，只给测试与自检用。
> 它是**故意做脏的**，不要"修好"它——修好了就失去测试价值。

## 故意埋的坑

| 坑 | 在哪 | 期望行为 |
|---|---|---|
| 无卡类型后缀 | `陆九.md`、`磨坊.md` | stage1 仍能归并（按内容判类型），或明确报"无法判定类型" |
| 日期做文件名 | `2019-03-12 随手记.md` | 当作素材读入，不因文件名跳过 |
| 乱码前缀 | `aaa_new_角色卡.md` | 按后缀识别为角色卡 |
| 年龄矛盾 | 陆九 38 岁 vs 32 岁 | **必须报冲突**，条目里带两个来源路径 |
| 缺 locked 段 / 缺关系段 | 多张卡 | 不因此判整卡无效 |

## 跑法

```bash
python scripts/preset_apply.py --apply mill-dirty --hidden-ok
python scripts/orchestrator.py --from 1
```

## 判据

- `data/setting/setting.json` 里有 `conflicts` 记录，且至少 1 条含两个来源路径
- 冲突没被"自动消解"（不许悄悄选 38 或 32）
- 素材有矛盾但流水线**不崩**（可以带警告继续）
