# 出厂预设 · 盐镇旧事

**验什么**：跨 20 年（1998 / 2008 / 2018）时间线不串、人物年龄与关系可推演、
物证链（借条 / 盐票 / 花名册）不凭空出现或消失。

**规模**：10 章 × 5000-7000 字，现实乡土。

## 跑法

```bash
python scripts/preset_apply.py --apply salt-town
python scripts/orchestrator.py
python scripts/nfctl.py check
```

## 判据

- **年份可辨**：每章开头 200 字内必须能让读者判断"这是哪一年"（不要求写年份，
  要求有可推断的锚点：盐票、改制、停产、遗址公园）
- **年龄自洽**：陈守田 1998 年 42 岁、2018 年 62 岁；陈招娣 12 / 32。写错即失败
- **物证不消失**：盐票 2018 年仍在陈守田手里（locked）
- **不许煽情**：苦难不能替代事件推进——整章只有情绪没有事件即判退化
- 自动：`python tests/unit/test_presets.py`

## 注意

这是四套里**最容易写得"对但不好看"**的一套：现实题材没有超自然钩子，
全靠物证和年份推进。如果 10 章读下来像流水账，说明 stage3 的"每章一个转折"没落地。
