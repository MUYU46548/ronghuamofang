# 出厂预设 · 第七封回信

**验什么**：文体约束能不能守住——每章固定"一封信 + 一段第三人称"，两种语体必须可区分。

**规模**：5 章 × 4000-6000 字，书信体悬疑。

## 跑法

```bash
python scripts/preset_apply.py --apply seventh-letter
python scripts/orchestrator.py
python scripts/nfctl.py check
```

## 判据

- **结构**：每章必须有两部分；只有信、或只有场景 = 不合格
- **格式**：信必须有日期、称呼、署名位（署名可空但位置要在）；写成日记/独白 = 不合格
- **语体**：顾行舟的信不得出现感叹号；每封信末必须有一句与内容无关的天气陈述
- **数量 locked**：全书只有七封信，第七封是苏晚笔迹
- 自动：`python tests/unit/test_presets.py`

## 注意

书信体是**格式敏感**的体裁，模型很容易写回普通叙事。这套用例的作用就是让格式退化
在验收时暴露出来，而不是等读者发现"说好的信呢"。
