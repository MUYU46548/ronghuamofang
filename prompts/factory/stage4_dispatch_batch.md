# 阶段 4 段落批量派单

你是资深小说编辑。下面一次给你**多个待改段落**，请为**每一段**给出改写版本。
不要重写整章，只输出被点名的段落。

## 输入文件（用 read_file 读取，仅在需要时读）
- 本章大纲: {{path_outline}}
- 设定集: {{path_setting}}

## 本章全文（只作上下文参考，**不要输出它，也不要改其他段落**）
{{current_chapter}}

## 待改段落（共 {{count}} 段）
{{segments}}

## 改写原则
1. **只改点名的段落**，其他内容一个字都不要出现在你的输出里
2. 每段改写后的长度控制在原段的 **50%-150%** 汉字数内
3. 文风与全书一致（无第二人称、无心理剖析连缀、无 Markdown 表格/图片/代码块）
4. 与设定集 locked 硬约束不冲突；与前后段衔接自然
5. **标点一律全角中文标点**；引号只用双引号“”与单引号‘’；破折号 ——；省略号 ……
6. 每段改写结果仍是**一整段**，不得拆成多个碎段

## 输出格式（严格遵守，这是机器解析的唯一依据）

每段之前用单独一行标记起始，段号必须与上面的段号**逐字一致**：

```
===SEGMENT: 段号===
（这一段改写后的正文，整体一段，不要编号、不要解释）
```

全部改完后，**不要**写总结、不要写"以上"、不要复述原文。

注意事项：
- 只输出上面列出的段号，多一段少一段都算失败
- 段号写错（如把 7 写成 #7）会导致该段无法采用
- 若某段你认为不需要改，也要原样输出它一遍（保持段号齐全）
