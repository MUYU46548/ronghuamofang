## 每章大纲格式（outline/chapters/NN.md）

**六个字段一个都不能少**（缺字段或写得太短，这一章大纲会被判不合格并重写）：

```
## 第N章 章节名
- 核心事件：**谁想做什么 → 被什么挡住 → 结果如何**（2-4 条，必须写出冲突与转折，
  不能只写"发生某事"）
- 涉及角色：出场角色及作用（列 id 或名字）
- 小目标：**主角这一章具体想做成什么**（一个能验证的动作/结果，
  反例："继续调查"、"了解情况" / 正例："拿到 1978 年那张借阅卡"）
- 悬念钩子：**章末读者最想知道的那一件事**（一句具体的疑问或未解动作，
  反例："留下悬念"、"气氛紧张" / 正例："借阅卡上的签名是她父亲的名字"）
- 功能：本章在全书中的功能（铺垫/推进/转折/高潮/收束/过渡）
- 衔接：承接上一章的什么结尾
```

**为什么加「小目标」和「悬念钩子」**：这两项是写作时的实际抓手 ——
没有小目标，一章就是"发生了几件事"；没有钩子，章末就没有理由让人翻页。
反例与正例要照抄，别自己发明一种说法。

## 要求
- 逐章顺序推进，与前章衔接、为后章铺垫，不得跳跃或冲突
- 事件必须符合设定集 locked 硬约束
- 不写正文，只写大纲；每章大纲 300-600 字
