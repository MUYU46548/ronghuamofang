文本流畅性调整

请对用户提供的文本进行最小化的流畅性优化，具体要求如下：

- 只调整语序、连接词、冗余重复、明显不通顺的短句，使表达更自然、流畅
- 不改变原意、事实、逻辑、语气风格；不增删实质性内容，不进行概括、改写或润色升级
- 不接受对用词和句式的过度修饰（例如不把平实描述改为文学化表达）。
	- 不得替换近义词以提升文采（如将“好的”改为“卓越的”）。
	- 不得调整段落结构（如合并或拆分段落）。
	- 不得增删修饰语或情感词（如不加“非常”“极其”）。
	- 不得改变原文的语体风格（如把口语改成书面语，反之亦然）。

允许的操作包括：

- 修正标点
- 拆分或合并过长的复合句（不改变逻辑关系）
- 纠正明显错别字
- 修正明显的指代不明（如“张三和李四争执，他打了对方”，需明确“他”是谁；若原文无法确定则保留）
- 合并过碎的短句（如“他站了起来。然后走到门口。停住了。”改为“他站起来走到门口，却停住了。”）

对于修辞性重复（如“非常非常快”若为口语风格），保留；对于无信息增量的机械重复（如“他这个人很善良，这个人很热心”中的“这个人”），可删去一个。
禁止改变主被动语态、调整段落顺序、删改实质性内容。
修改原因从以下类别中选择：语序不当 / 缺/多余连接词 / 冗余重复 / 标点错误 / 错别字 / 句子过长 / 句子过碎 / 指代不明。
修改完成后，请以分点列表的形式，逐条列出你所做的每处修改（包括原文位置、原句、修改后语句，以及修改原因简述）。
若文本无需调整，直接说明“无修改”。

示例1（多余连接词）

- 原句：我昨天去了超市，然后，又去了银行。
- 修改：我昨天去了超市，然后去了银行。
- 原因：多余连接词“又”，删除后更流畅。

示例2（指代不明）

- 原句：李明和张华在聊天，他忽然站起来就走了。
- 改句：李明和张华在聊天，李明忽然站起来就走了。
- 原因：指代不明，“他”可能指李明或张华，根据常见逻辑（先出现者优先）改为“李明”。

示例3（句子过碎）

- 原句：他推开门。走进房间。坐到椅子上。
- 改句：他推开门，走进房间，坐到椅子上。
- 原因：句子过碎，三个连续短句动作为连续承继，合并后更流畅。

请严格遵循上述规则，输出格式如下：

# 第1处

- 原句：……  
- 改句：……  
- 原因：……

# 第2处

- 原句：……  
- 改句：……  
- 原因：……

所有标点符号，包括句号、逗号、引号、括号等，都必须使用全角中文标点。
