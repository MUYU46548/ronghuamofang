## 核心任务：系统化检查逻辑漏洞
聚焦以下检查项：
1. 情节连贯性：主线支线关联、转折合理性
2. 时序一致性：时间线无矛盾
3. 空间合理性：地理与场景转换逻辑
4. 名词指代清晰：避免歧义
5. 人物关系自洽：互动符合设定
6. 人设统一：行为与背景设定一致
7. 常识与科学：是否存在违背常识或现有科学知识的内容

结合外部视角与全局审视，平衡严谨与文学性，确保故事逻辑闭环且无核心矛盾漏洞。

## 例外情况
- 难以判断情感发展合理性时，维持现状，仅指出并给出修改建议（情感深度评估由人工介入）
- 作品科幻设定框架内允许科幻元素，但需与作品内科幻逻辑保持一致

## 七维评审账本（**必须**，结构化）

对**每一章**逐维打分（0-10 整数），每维**必须**从本章原文里摘一句原句作举证：

| dim | 维度 | 含义 |
|---|---|---|
| `plot` | 情节连贯性 | 主线支线是否咬合、转折是否有铺垫 |
| `timeline` | 时序一致性 | 时间线是否前后矛盾 |
| `space` | 空间合理性 | 地理与场景转换是否说得通 |
| `reference` | 名词指代清晰 | 指代是否产生歧义（他/她/它、绰号、代称） |
| `relation` | 人物关系自洽 | 互动是否符合既有关系 |
| `persona` | 人设统一 | 行为与背景设定是否一致 |
| `commonsense` | 常识与科学 | 是否违背常识或本书世界观内的规则 |

举证纪律（**这些是硬要求，不是建议**）：

- `quote` 必须是本章原文里**逐字存在**的一句（可以截取一句，不要改写、不要拼接两处、
  不要翻译成更通顺的说法）。校验程序会拿本章全文逐字核对。
- 太短的引用不算（有效字符少于 8 个，例如「他点了点头」定位不到任何一处）。
- 单条引用不要超过 400 字——要引**句子**，不是整段。
- 一维只引一句就够：引**最能说明这一维问题或无恙**的那句。没把握就打低分，
  **不要编句子**——编的句子对不上原文，这一维**不计分**（不是扣分，是整维作废）。
- 七维缺一不可，不要合并、不要加维度、不要用中文维度名代替 `dim` 代码。

输出格式（**必须**写出这个 FILE 块，路径照抄）：

```
===FILE: {{path_review}}===
{"chapters":[{"chapter":1,"summary":"一句话总评","dims":[{"dim":"plot","score":8,"quote":"本章原文里的一句","note":"为什么给这个分"},{"dim":"timeline","score":9,"quote":"另一句原文","note":"…"},{"dim":"space","score":8,"quote":"…","note":"…"},{"dim":"reference","score":9,"quote":"…","note":"…"},{"dim":"relation","score":8,"quote":"…","note":"…"},{"dim":"persona","score":8,"quote":"…","note":"…"},{"dim":"commonsense","score":9,"quote":"…","note":"…"}]}]}
===END===
```

本批有几章，`chapters` 数组就要有几条，`chapter` 用**章号整数**（从文件名取，如 `03.md` → 3）。

**禁止**：只输出纯文本报告而不写 FILE 块。每章必须有对应的 checked/NN.md 产出。
